# 分布式推理

使用 P 表示 prefill 阶段，D 表示 decode 阶段。  
PD 分离将这两个阶段交给不同计算资源  
AF 分离将每层的注意力和前馈网络交给不同资源

## 计算与状态的分布方式

### 计算资源，推理实例与服务副本

P，D 由同一组执行资源处理的方式称为 共置

设每个请求在某类副本上的 prefill 和 decode 分别占用 $d_P$ 和 $d_D$ 秒，两个阶段在副本上串行执行，  
则 N 个相同共置副本的请求率上限为：

$$
\mu_{co} = \frac{N}{d_P + d_D}
$$

### 计算分工与状态共享

| 部署方式     | 期望收益                           | 主要约束                                   |
| ------------ | ---------------------------------- | ------------------------------------------ |
| 增加完整副本 | 处理更多独立请求，分散排队         | 模型复制，缓存分散，启动及保持实例运行成本 |
| PD 分离      | 分别配置两个阶段                   | KV 交接，两段同时占用内存                  |
| AF 分离      | 分别配置注意力和前馈网络           | 逐层激活往返，同步，流水线各阶段的负载均衡 |
| 共享 KV      | 跨实例复用上下文，减少重复 prefill | 缓存标识，读取，就绪通知，失效与空间释放   |

### 同一请求的执行路径与状态驻留时间

带视觉输入时，先在编码阶段 E 将图像转换为模型使用的特征，EC 保存这些编码结果供复用  
P 处理这些编码结果与文本，D 逐步生成输出
