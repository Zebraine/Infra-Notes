## 网络形状与计算组织

### 深度，宽度与专家粒度

若 FFN 宽度与隐藏维度保持固定比例，稠密主干的参数量大致正比于 $Ld^2$，其中 $L$ 是层数，$d$ 是隐藏维度。  
隐藏维度减半的情况下，将层数增加为四倍，这部分参数量保持相近，但是逐层依赖链的长度增加为四倍。

对于专家结构，在保持参数量与运算量不变的情况下。  
设单层路由专家的总参数量为 $3Edf$，单 token 的专家运算量为 $6k_{top}df$，其中 $E$ 是专家总数，$f$ 是专家中间维度。  
如果将专家数和选中数都减半，专家中间维度翻倍，则这两个量都不变。

### 残差连接与跨层状态

残差连接将子层输入直接加到变化结果上，形成了一条原始信息与梯度之间的捷径。  
普通的残差计算逐层计算，因此每一层都要保存对应输入 $x_l$。

普通的残差会将不同深度的信息加到同一条通路中，形成了一个跨层的状态。  
但是层间信息组合方式的多样性有限，无法充分利用不同深度的特征。  
DeepSeek V4-Flash 使用 **mHC** (流形约束超连接) 结构，将一条残差通路扩展为多条，并约束通路之间的混合系数，使得不同深度的特征可以在不同通路中独立组合。  
在使用残差混合矩阵前，先将矩阵 Sinkhorn 迭代归一化，使各行与列的和都接近 1，使多层混合中的数值更稳定。

Kimi K3 希望模型不只是接收混合结果，而要能按需选取所需的信息。  
因此使用 Attention Residuals （AttnRes，注意力残差连接)，通过模拟注意力计算方式，使模型可以有选择地学习/遗忘特定层的特征。  
同时在实际工程中，为了减小显存与计算开销，采用 Block AttnRes，将网络层分块，块内采用普通的残差连接，块间采用 AttnRes。

### 多 token 预测与辅助计算

多 token 预测(MTP) 是一种在训练阶段同时预测多个 token 的方式。

推测解码 是先用较低开销生成候选的 token 序列，再让模型验证这些候选。  
MTP 可以先根据当前主干特征预先生成多个候选 token，再将这些候选 token 送入模型进行验证。  
最终从最后一个通过验证的位置继续下一轮的生成。

设一次普通 decode 需要时间 $T_d$，一次推测解码的候选与验证耗时为 $T_s + T_v$，平均得到 $\bar{g}$ 个有效输出。  
这种情况下，想要 MTP 带来速度上的提升，需要满足：

$$
\bar(g) > \frac{T_s + T_v}{T_d}
$$
