## 计算图与前项执行

### 序列依赖与因果计算图

序列依赖是指在计算过程中，某些操作必须按照特定的顺序执行，因为后续操作依赖于前面的结果。  
因果计算图是在计算过程中，节点之间的依赖关系可以用有向图表示。  
图中每个节点表示一个计算操作，边表示依赖关系。  

例如循环神经网络 (RNN)，前一 token 位置的状态会传给后一 token 位置， token状态满足 $h_t = f(x_t, h_{t-1})$。  
其中 $x_t$ 是当前输入， $h_{t-1}$ 是前一时刻的状态，$f$ 是基于模型权重所做的变换。  
由于当前结果依赖前一 token 位置，所以同一层按位置顺序执行，即使输入全部到达，也无法并行计算。

而 Transformer 模型中，前一 token 位置的状态不会传给后一 token 位置，token 状态满足 $h_t = f(x_t)$。  
因此同一层的所有 token 可以并行计算，前一层的输出可以同时作为后一层的输入，形成了一个前项计算图。
但是，前一层的输出必须在后一层开始计算之前完成，因此不同层之间存在序列依赖。

### 模型配置与张量结构

设本次对 m 个输入 token 进行推理，每个 token 用包含 k 个特征的向量表示。  
将这些向量堆叠成一个张量 $X \in \mathbb{R}^{m \times k}$，其中每一行表示一个 token 的特征向量。  
设输出宽度为 $n$， 则参数矩阵 $W \in \mathbb{R}^{k \times n}$，输出张量 $Y \in \mathbb{R}^{m \times n}$。

每个输出元素 $y_{ij}$ 是输入向量 $x_i$ 与参数矩阵 $W$ 的第 j 列的点积，需要 $k$ 次乘法和 $k-1$ 次加法。  
因此有：
$$
N_W = kn,\quad F = 2mkn, \quad M_W = b_Wkn
$$
其中 $N_W$ 是参数数量，$F$ 是总计算量，$M_W$ 是需要的存储空间，$b_W$ 是每个参数占用的字节数。  
m 翻倍时，运算量翻倍，但权重大小不变。  
n 翻倍时，权重和运算量都翻倍。  

一次**前向执行**是指使用当前权重，从输入算到输出的过程。  
隐藏向量是网络内部传递的特征表示，维度是每个 token 的向量长度。  
**前馈网络**(FFN) 对每个 token 分别做特征变换，**注意力** 在token之间选择并汇总信息，两类运算交替组成网络的一层。
