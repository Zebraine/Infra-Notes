## 远程访问的路径与并发

### 数据传输与完成通知

一次数据交接包含两项工作：  
- 将分片写到目标卡可以读取的位置
- 让目标卡知道数据已经就绪

双边消息 需要发送方与接收方配合，接收方先提交接受请求并提供缓冲区，通信系统将到达的消息与相应请求配对。  

写入和通知完成数据交接后，还需要接收方按指定方式处理数据，这一步叫做 远程过程调用 (RPC)。  
具体是请求对端执行指定的函数，包含传参数，远端执行和返回结果。

### 由产生数据的加速器直接发起通信

NVIDIA 的 GPUDirect RDMA 允许网卡直接访问 GPU 内存，而不需要主机内存中转。  
加速器也可以直接发起通信，构成了 GPU 到 GPU 的直接通信路径。

### 内存语义：Load / Store 与 Read / Write

Load / Store 是 CPU 内存访问的语义，Read / Write 是网络通信的语义。
