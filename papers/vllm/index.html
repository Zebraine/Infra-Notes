摘要§

高吞吐地服务大语言模型（LLM）需要一次批处理足够多的请求；但每个请求的键值缓存（KV cache）巨大且动态伸缩，现有系统难以高效管理。管理不当时，显存会被碎片和冗余副本大量浪费，限制批大小。为此，我们提出 PagedAttention——一种受操作系统虚拟内存与分页技术启发的注意力算法。在它之上我们构建了 vLLM 服务系统，做到（1）KV 缓存显存近乎零浪费；（2）请求内与请求间灵活共享 KV 缓存，进一步降低显存占用。评估表明，在相同延迟水平下，vLLM 将主流 LLM 的吞吐相比 FasterTransformer、Orca 等 SOTA 系统提升 2–4 倍；序列更长、模型更大、解码算法更复杂时收益更明显。vLLM 源码已开源：https://github.com/vllm-project/vllm。

1 精读导读§

vLLM 是把“KV cache 显存管理”变成一等问题的那篇论文。Orca 解决了如何连续地调度迭代；vLLM 解释了这些迭代使用的显存为何被严重碎片化，以及如何修好它。观察几乎简单得过分：现有引擎会为每个请求按最大可能长度预留一块连续 KV 区域。实际长度未知且通常短得多，于是大部分预留被浪费；长期存活的请求还会挡住新请求，共享前缀的序列也无法共享物理显存。

PagedAttention 借用了操作系统的答案：固定大小的页、每请求一张页表、写时复制共享。KV cache 变成一组不必连续的块；注意力 kernel 按块表收集 K/V，对模型保持逻辑连续，对物理显存则可以按需分配和共享。

这就是 vLLM 做成广泛使用的开源服务引擎的设计，也是 prefix caching、显存感知调度以及后来大量服务论文（包括 BidKV 的 KV 压力视角）的直接前身。

2 问题与背景§

LLM 服务是显存受限的。对 40 GB A100 上的 13B 模型，约 65% 显存存放静态模型权重，接近 30% 存放动态 KV cache，只有很小一部分用于激活。KV cache 随 token 生成而增长或收缩，其生命周期和最终长度事先未知。现有系统把每个请求的 KV cache 存在连续显存中，因为多数深度学习框架要求张量连续。

这种设计造成三类浪费。预留（reserved）：按最大序列长度分配却从未使用；内部碎片：实际长度小于预留长度；外部碎片：不同大小的连续块之间留下无法使用的空隙。论文的 profiling 显示，现有系统实际只用到 20.4%–38.2% 的 KV cache 显存。浪费限制批大小，批大小又限制吞吐。

3 方法§

3.1 PagedAttention§

PagedAttention 把每个请求的 KV cache 切成固定大小的块，每块存放 \(B\) 个 token 的 key 和 value。每个请求维护一张块表，把逻辑块映射到 GPU 显存中的物理块；物理块不必连续。给定 query \(q_i\) 和第 \(j\) 个块中的 key \(K_j\)、value \(V_j\)，块级注意力为

\[ A_{ij}=\frac{\exp(q_i^{\top}K_j/\sqrt{d})}{\sum_{j'}\exp(q_i^{\top}K_{j'}/\sqrt{d})}, \qquad o_i=\sum_j V_j A_{ij}^{\top}. \]

kernel 读取块表，收集 K/V 块并在其上计算注意力。因为块大小固定，内部碎片最多浪费最后一个块，外部碎片则消失；显存随生成过程按需分配，因此接近零浪费。

3.2 KV 缓存共享与调度§

块表还带来共享能力。并行采样或 beam search 时，多个输出序列可以让共享前缀指向同一批物理块；当某个序列要向共享块写入新 token 时，vLLM 用写时复制创建私有副本。跨请求的共享前缀同理。论文报告 beam search 最多节省 55% 显存，共享 prompt 也有显著收益。

vLLM 的调度器按 FCFS 组批，物理块耗尽时进行抢占：可以把块换出到 CPU，或丢弃后重算；对于单卡放不下的模型，它使用张量并行。块管理器、调度器和注意力 kernel 是协同设计的：调度器分配块，块表广播给 worker，kernel 按块表访问正确的物理显存。

4 实验与结果§

论文在 OPT-13B、OPT-66B、OPT-175B 上使用 ShareGPT 和 Alpaca 轨迹评估。与 FasterTransformer、Orca 相比，vLLM 在相同延迟下吞吐提升 2–4 倍；序列越长、模型越大、解码算法越复杂，收益越明显。主实验中 vLLM 的 KV cache 显存浪费低于 4%，而基线为 60%–80%。

论文还表明 PagedAttention 不改变模型精度——它改变的是显存布局，不是注意力数学；共享与写时复制在并行采样、beam search 中带来大幅节省。系统通过张量并行支持超过单卡容量的模型。

5 影响与局限§

PagedAttention 与 vLLM 改变了 LLM 服务的默认显存模型。基于块的 KV 管理、前缀缓存、写时复制共享如今已是标准思路，vLLM 本身也成为最广泛使用的开源服务引擎之一。论文还把 KV cache 变成服务研究的中心对象：一旦显存可以分页，就可以在更丰富的设计空间里讨论驱逐、共享、抢占和调度。

局限主要在范围。论文关注给定延迟下的吞吐，没有深入优化 SLO、公平性或优先级；块大小是碎片与 kernel 效率之间的权衡；跨请求前缀缓存带来失效和安全问题。此外，PagedAttention 仍要对所有缓存 token 做完整注意力，不能降低超长上下文的二次计算——后来的 FlashAttention 和 MLA 才从另一条轴解决这个问题。
