关于这个论文库§

这里是 AI Infra 方向系统论文的中文精读与原文对照。每篇论文都保留原始 PDF、英文原文、 逐节中文译文，以及从原文裁切的图表；公式、表格和章节编号尽量与原文一致。

本站是一个纯静态站点：内容是可移植的 Markdown，页面、目录、搜索索引和资源清单都由 utils/ 下的构建器生成。没有数据库，也没有运行时后端。

提示块§

写作约定

术语第一次出现时保留英文原文，例如 prefill（预填充）、victim（被抢占请求）。 公式中的符号与原文保持一致，方便逐条核对。

文件结构§

papers/
  bidkv/
    meta.yaml          # 标题、作者、摘要、标签、封面
    zh.md              # 中文译文
    original.md        # 英文原文
    assets/
      source.pdf       # 原始 PDF

  index.html           # 论文库首页（生成）
  bidkv/index.html     # 译文页（生成）
  bidkv/original/      # 原文页（生成）

新增一篇论文§

python3 utils/new_paper.py \
  --slug my-paper \
  --title "Paper Title" \
  --title-zh "论文中文标题" \
  --url "https://example.com/paper.pdf" \
  --year 2026

# 编辑 papers/my-paper/zh.md、original.md 和 meta.yaml
./utils/build.sh

构建器会校验中英文标题层级、图片路径、重复 id 和缺失资源。若两版章节结构不一致， 语言切换会报错，而不是悄悄跳到错误位置。

设计取舍§

  • 静态优先：所有页面可直接用浏览器打开，不需要服务器；KaTeX、Mermaid 全部本地化。
  • 章节 id 对齐：中英文使用同一套 sec-* id，切换语言时保留当前阅读位置。
  • 内容与样式分离：论文只写 Markdown；版式、目录、灯箱、搜索都在 utils/ 中维护。
  • 可校验：构建失败比发布坏链接好；--strict 会把警告升级为错误。
