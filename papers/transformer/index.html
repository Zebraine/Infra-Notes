摘要§

主流的序列转导模型基于复杂的循环或卷积神经网络，包含编码器与解码器；性能最好的模型还会用注意力机制连接编码器和解码器。我们提出一种新的简单网络架构 Transformer，它完全基于注意力机制，彻底舍弃循环和卷积。两个机器翻译任务上的实验表明，这类模型质量更优、更易并行化，训练时间也显著缩短。在 WMT 2014 英德翻译任务上，我们的模型取得 28.4 BLEU，超过此前最佳结果（包括集成模型）2 BLEU 以上；在 WMT 2014 英法任务上，模型在 8 块 GPU 上训练 3.5 天后取得 41.8 BLEU 的单模型新 SOTA，训练成本仅为文献中最佳模型的一小部分。我们还将 Transformer 成功应用于英语成分句法分析（包括大规模和有限训练数据），说明它可以泛化到其他任务。

1 精读导读§

Transformer 是几乎所有现代语言模型的架构原点。2017 年之前，最强的序列模型是循环网络：计算必须逐 token 前进，训练无法充分利用 GPU 的并行能力。Transformer 用注意力取代循环，把一个序列问题变成一叠稠密矩阵乘法。正是这一改变，让“用更多数据、更大 batch 训练更大模型”成为工程上可行的事，也奠定了后来 BERT、GPT、T5、LLaMA、DeepSeek 的规模化叙事。

从系统角度看，这篇论文有三层奠基意义。第一，自注意力是典型的 GEMM 密集型负载，其算术强度和显存访问决定了训练与服务成本。第二，模型不在 token 之间传递隐状态，因此训练和推理都可以沿序列维度并行。第三，注意力矩阵的 \(O(N^2)\) 复杂度制造了显存压力，后来围绕 KV cache、PagedAttention、FlashAttention、MLA 和抢占调度的研究，本质上都在管理这笔开销。

本精读版保留论文原始摘要和核心技术段落的对译，并补充结果与影响的导读；完整实验附录和消融实验请查阅 PDF。

2 问题与背景§

循环模型通常沿输入、输出序列的符号位置分解计算：它把位置对齐到计算时间步，用前一时刻隐状态 \(h_{t-1}\) 和当前输入生成 \(h_t\)。这种固有的顺序性使得训练样本内部无法并行，序列越长问题越严重——显存约束又会限制跨样本的批处理。

注意力机制早已成为序列建模和转导模型的重要组成部分，它可以在不依赖输入/输出距离的情况下建模依赖关系；但在 Transformer 之前，注意力几乎总是与循环网络配合使用。Transformer 是第一个完全依靠自注意力来计算输入、输出表示、不使用序列对齐 RNN 或卷积的转导模型。

3 方法§

3.1 缩放点积注意力与多头注意力§

注意力函数把 query 和一组 key-value 对映射为输出：输出是 value 的加权和，权重由 query 与对应 key 的兼容性函数计算。论文采用缩放点积注意力：

\[ \mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V . \]

当 \(d_k\) 较大时，点积幅值会变大，softmax 会进入梯度极小的区域；除以 \(\sqrt{d_k}\) 可以抵消这一效应。模型没有只做一次注意力，而是用可学习的线性投影把 query、key、value 投影 \(h\) 次，并行计算注意力，拼接后再投影一次：

\[ \mathrm{MultiHead}(Q,K,V)=\mathrm{Concat}(\mathrm{head}_1,\ldots,\mathrm{head}_h)W^O, \]
\[ \mathrm{head}_i=\mathrm{Attention}(QW_i^Q,KW_i^K,VW_i^V). \]

多头注意力让模型可以在不同位置、不同表示子空间里同时关注信息。论文还比较了加性注意力和点积注意力，指出点积注意力在实践中快得多、空间效率也更高，因为它可以写成高度优化的矩阵乘法。

3.2 编码器—解码器堆叠与位置编码§

编码器由 \(N=6\) 个相同层堆叠而成。每层有两个子层：多头自注意力和逐位置全连接前馈网络；每个子层外都有残差连接，随后做层归一化。解码器同样由 6 层组成；除了编码器层中的两个子层，解码器还插入第三个子层，对编码器输出做多头注意力。解码器自注意力中的掩码阻止当前位置关注后续位置，从而保留自回归性质。

由于模型既没有循环也没有卷积，位置信息必须显式注入。论文把正弦位置编码加到输入嵌入上：

\[ PE_{(pos,2i)}=\sin\!\left(\frac{pos}{10000^{2i/d_{\mathrm{model}}}}\right),\qquad PE_{(pos,2i+1)}=\cos\!\left(\frac{pos}{10000^{2i/d_{\mathrm{model}}}}\right). \]

这些波长构成等比数列，使模型可以按相对位置关注，并外推到比训练时更长的序列。base 模型使用 \(d_{\mathrm{model}}=512\)、\(h=8\)、\(d_k=d_v=64\)，前馈内层维度 2048；big 模型使用 \(d_{\mathrm{model}}=1024\)、\(h=16\)，前馈维度 4096。

4 实验与结果§

模型在 WMT 2014 英德和英法翻译任务上训练。big Transformer 在英德上取得 28.4 BLEU，比此前最佳结果（包括集成模型）高出 2 BLEU 以上；在英法上，单模型在 8 块 P100 上训练 3.5 天后取得 41.8 BLEU，训练成本仅为文献最佳模型的一小部分。base 模型在 8 块 P100 上约 12 小时即可训练完成，英德、英法分别达到 27.3 和 38.1 BLEU。

论文还表明 Transformer 可以泛化到翻译之外：在 Wall Street Journal 和有监督/半监督设置下的英语成分句法分析上都取得强结果。消融实验显示多头注意力、正弦位置编码和模型规模都重要；论文还分析了注意力头的 specialization，以及层数、头数的影响。

5 影响与局限§

Transformer 用并行、基于注意力的计算图取代了循环网络的顺序归纳偏置。这一转变让“更多数据、更大模型”成为可能，直接开启了 BERT/GPT/T5 时代。在服务系统里，同一个注意力算子又成为 KV cache 和 prefill 二次开销的来源，主导了 LLM 推理的成本结构。

论文的局限同样重要：自注意力的时间和显存复杂度都是序列长度的 \(O(N^2)\)，实验集中在翻译和句法分析而不是开放式生成；论文没有 KV cache，训练和评估的序列也相对较短。正是这些空白，催生了高效注意力 kernel、分页 KV 显存、潜变量注意力和长上下文训练——也就是这个论文库中许多后续工作的主题。
